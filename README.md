Survival 3D: Escape from the Island 

A complex 3D survival game featuring inventory management, crafting, and AI systems.

Core Systems (Implemented)
Input System: Modern Unity Input System (Keyboard/Mouse + Controller support).
Inventory & Crafting:
                      Pick up/Drop/Stack items.
                      Resource gathering (Wood/Stone mining).
                      Crafting system & UI binding to player stats.
Save/Load System: JSON-based serialization for complex game data.
AI: NPC State Machine using NavMeshAgent.
Environment: Day/Night cycle, Water physics implementation.

Tech Stack
Architecture: State Machines for AI, JSON Serialization.
Unity Features: NavMesh, New Input System, Physics API.

Roadmap
